# Security policy

This portfolio is a public static site.

## Public-content rules

- Do not commit credentials, secrets, `.env` files, private keys, AWS access keys, session tokens, or confidential reports.
- Redact AWS account IDs, internal hostnames, employee data, private IP addresses, and sensitive log fields before publishing project evidence.
- Use synthetic or intentionally generated findings for demonstrations.
- Keep project status honest: planned work remains labelled **Planned Lab** until implementation and validation are complete.

## Reporting an issue

Use the LinkedIn contact link on the portfolio to report a security or privacy concern.
