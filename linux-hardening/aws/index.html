PROJECT 01B / LINUX SERVER HARDENING / AWS EXTENSION

PLANNED IMPLEMENTATION

AWS EC2 hardening

This is the AWS track of my Linux Server Hardening project. It extends the completed local VirtualBox investigation into a repeatable EC2 baseline, with controlled administration and evidence that the controls work.

Back to project tracks ↗ View completed local Project 01A ↗
Target

Ubuntu EC2 instance in an isolated AWS lab environment.

Objective

Apply a secure baseline consistently and make privileged access auditable.

State

Planned project. No AWS deployment or test results are claimed as complete.

What this project will cover

Build plan

Provision and harden

  • Provision a scoped EC2 host and supporting network controls with Terraform.
  • Apply Linux baseline settings with Ansible, including SSH, permissions, firewall rules, and audit logging.
  • Use Systems Manager for managed administration where practical and record administrative access.

Evidence plan

Verify the security outcomes

  • Show the baseline configuration and the changes applied to the host.
  • Test allowed administration and denied access paths.
  • Run a security assessment and document findings, remediation, and repeat-run results.

Planned tools

Linux, Bash, Ansible, Lynis, OpenSCAP, auditd, UFW, Terraform, Amazon EC2, and AWS Systems Manager.
